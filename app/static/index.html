Installing a file

  • Console (Tiger Touch etc.): copy the .d4 to a USB stick, then into D:\Personalities on the console. Restart Titan.
  • Titan PC / Simulator: put it in Documents\Titan\Personalities. Restart Titan.
  • Files in that user folder take priority over the built-in library and survive library updates.
